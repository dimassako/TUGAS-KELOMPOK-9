Pemrograman Back-End — Institut Teknologi Tangerang Selatan

// deskripsi

Website ini dibuat sebagai tugas kelompok mata kuliah Pemrograman Back-End di ITTS. Menampilkan data Pokémon dari API publik secara dinamis menggunakan framework Flask (Python).

// fitur

  • 🔍 Search & Filter — Cari pokemon berdasarkan nama, ID, atau tipe
  • 📊 Halaman Detail — Stats lengkap, radar chart, dan mode shiny
  • ⚡ Perbandingan — Head-to-head 2 pokemon dengan visual bar
  • 🏆 Ranking — Sortir 151 pokemon berdasarkan berbagai stats
  • 💾 Cache sistem — Data disimpan lokal agar tidak perlu fetch ulang

// teknologi

  • Python + Flask — Web framework back-end
  • Library requests — Pengambilan data dari API publik
  • HTML Template Jinja2 — Data dinamis dengan looping & kondisi
  • Chart.js — Radar chart visualisasi stats
  • PokeAPI — Sumber data API publik gratis

// api endpoint

Nama: PokeAPI

URL: https://pokeapi.co

Endpoint: GET /api/v2/pokemon?limit=151

Auth: Tidak diperlukan — gratis & publik

Format: JSON
